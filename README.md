# Vivero de Tortugas — App móvil con Framework7

App móvil para los voluntarios del vivero de tortugas marinas, hecha con Framework7 9 + React 19.

## Ejecución

```bash
npm install
npm start
```

Abrir http://localhost:5174. Usuarios de prueba: `coordinador` o `consulta`, contraseña `vivero123`.
